How to review a book

  1. Click Open the Library below and pick any book to open the reader.
  2. Turn on ✓ Review in the top bar of the reader.
  3. On each page, compare the picture with the words. Mark Text, Image, Page order and Layout as OK or Needs edit.
  4. Pick an Issue type and set a Status (open / fixed / ignored) if needed.
  5. Type exactly what needs fixing in Notes. It saves on its own — you’ll see Saved ✓.
  6. Move through every page, including the front and back cover.
